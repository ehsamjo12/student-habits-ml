# Student Habits vs Academic Performance

Exploring the relationship between student lifestyle habits and academic performance using data analysis and machine learning.

## Dataset

The dataset contains simulated student records covering study habits, sleep, social media usage, diet, mental health, and academic performance.

Project currently in development.
